# Using the Shift Projects template in Google Slides

`templates/Shift-Projects-Template.pptx` is a real PowerPoint file: 19 slides on 10 layouts (Cream, Lumber, Slate, Olive and Washed Black, each with and without the logo), the Shift colour theme, and native shapes. Nothing is a picture except photos you add, so everything stays editable.

## Get it into Slides (about a minute)
1. Open drive.google.com and drag `Shift-Projects-Template.pptx` into My Drive (or New > File upload).
2. Right-click the file > **Open with > Google Slides**.
3. File > **Save as Google Slides** so you have a native copy. Keep that copy as the master and **Make a copy** for each new deck.

## Logo on every slide (and how to turn it off)
Every layout carries the Shift icon top-right. To remove it from one slide: right-click the slide > **Apply layout** > pick the matching **"(no logo)"** layout (for example *Shift - Cream (no logo)*). To remove it everywhere, delete the icon in Slide > Edit theme on each layout, or switch all slides to the no-logo layouts.

## Fonts
- Headlines use **Familjen Grotesk** (a stand-in for the brand's Apparat) and body uses **Inter**. Both are Google Fonts. If a font looks wrong: select the text > font menu > **More fonts** > search the name > add it.
- Apparat is licensed. If Shift owns it, install it on your computer for PowerPoint/Keynote; Google Slides cannot use it.

## Editing tips
- **Swap a photo:** Insert > Image, place it over the grey tile, then right-click > Order > Send to back; delete the tile.
- **Colours:** use the theme palette (Fill colour > Theme) so the brand colours stay exact.
- **Footer text** ("Deck title") and the page number live on the layout: Slide > Edit theme, then pick the layout.
- **Add a slide:** right-click a slide in the sidebar > Duplicate slide.
- Animations from the HTML version are not included.

## Known limits
The stepped photo crop is a flat grey shape, not a mask. Slides cannot crop a picture to that outline, so place photos as rectangles over it or crop them in an image editor.
